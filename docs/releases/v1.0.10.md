# MiniMetersMobile 1.0.10

First public Windows release of the desktop side. This is the audio server the
[MiniMeters Mobile](https://github.com/SOMWHY/minimeters-mobile) app connects to.

## Downloads

`MiniMetersMobile-1.0.10-windows.zip` contains:

| File | What it is |
| --- | --- |
| `install.cmd` | One-click installer (elevates, copies both plugins, opens the firewall port) |
| `MiniMetersMobile.vst3\` | VST3 plugin (a folder — it is a bundle) |
| `MiniMetersMobile.clap` | CLAP plugin |
| `MiniMetersMobile.exe` | Standalone, no DAW required |
| `INSTALL.md` | Copy targets, DAW rescan steps, firewall notes |
| `LICENSE` / `SOURCE.txt` / `THIRD_PARTY_NOTICES.md` | GPL v3 compliance |

## Install in one paragraph

Unpack the zip and double-click **`install.cmd`**. It asks for administrator rights, copies the VST3
and CLAP bundles into `C:\Program Files\Common Files\{VST3,CLAP}\`, allows inbound TCP 8422 on
private networks, and tells you to rescan your DAW. The standalone `MiniMetersMobile.exe` runs
straight from the folder without installing anything. Manual steps and per-DAW rescan paths are in
`INSTALL.md`.

## ⚠️ This build is not code signed

## Connecting the phone

Open the plugin (or the standalone). It shows a QR code plus `Address` / `Path` / `Token` and a
120-second expiry. Scan it from the app, or type the values in by hand.

- Phone and computer must be on the same local network.
- Windows Firewall must allow inbound **TCP 8422** — otherwise the plugin reports
  `Network: unavailable`.
- The first pairing issues a device token, so later launches reconnect without the QR.
- `Refresh pairing` rotates the QR token; `Forget devices` invalidates every paired phone.

## Compatibility

| | |
| --- | --- |
| Protocol version | `1` |
| Minimum app version | `1.0.0` |
| Platforms | Windows x64 only in this release |
| Formats | VST3, CLAP, Standalone |
Protocol `1` is unchanged in this release, so any 1.0.x app pairs with this plugin and vice versa.

## Notes

- Windows only for now. macOS and Linux build scripts exist in the repository but their output has
  not been verified, so it is not published.
- The audio is passed through untouched — inserting the plugin does not change what you hear. It
  only taps the buffer and queues it for the phone.
